# NUN — Desktop system environment

A standalone, dependency-free desktop interface concept for the NUN operating-system project.

## Visual direction

NUN uses an architectural, low-glare palette: deep evergreen graphite, warm mineral surfaces, restrained copper accents and jade status colours. It is intentionally distinct from the consumer-facing NUNLauncher.

## Preview

Open `index.html` in a modern browser. No package manager, build tool or development server is required.

## Interface modules

- Workspace switcher and persistent engineering navigation.
- Project metadata cards with clear specification/runtime boundaries.
- Layered architecture blueprint with kernel, bootstrap and device boundaries.
- Project activity visualization, component inventory and module detail dialogs.
- Global component filtering, keyboard search shortcut and compact pinned tools.
- Responsive desktop/tablet/mobile layouts and reduced-motion support.

## Interaction and status

The buttons, navigation, search, dialogs and local clock are interactive. Project-state labels and graph data are illustrative interface content, not kernel telemetry.

NUN remains a specification scaffold: this web UI is not a bootable operating system and does not implement a kernel, filesystem, driver manager or command execution.


## Abstract layout interpretation

The hand-drawn grammar is expressed as a desktop system surface: a compact system status rail, a persistent engineering workspace rail, a wide open architecture field with independently inspectable layer nodes, contextual details and a pinned lower tool dock. NUN keeps its mineral, evergreen, copper and jade engineering palette; the sketch's yellow field is translated into restrained structural highlights rather than a full-screen colour fill.
