# Third-party source notices

NUN pins external source repositories as git submodules. Each submodule retains its own LICENSE, copyright and attribution notices. Review the license inside each pinned revision before redistributing a combined binary.

The Limine protocol header is fetched at a pinned protocol commit for local compilation. The Limine protocol header carries the 0BSD license notice in its source. The Limine boot manager release is a separate build input; its own license and release notices are retained with the downloaded distribution.

The repository does not vendor proprietary Delphi, VCL or FireMonkey components. The language compatibility plan targets documented source-level and ABI interoperability only.
