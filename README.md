# NUN — интеграционная основа системной ОС

NUN объединяет семь исходных репозиториев в одну проверяемую инженерную систему. Полный исходный код, тесты, конфигурации и история каждого проекта подключаются как закреплённые Git submodules.

## Что входит в NUN

- SAMBU — язык, интерпретатор, CLI, IDE, инженерные сценарии и инструменты разработчика.
- ToolNG — нативное ядро политик, доказательности и ограниченных workflow.
- ReaperCripple — bootstrap, rollback, BSP-адаптеры, телеметрия и производственные профили.
- Kloz — платформенный ABI, арена памяти и ресурсные лимиты.
- CO — детерминированный жизненный цикл компонентов.
- SaintSI — heartbeat, контроль состояния и CRC-32.
- Klipot — реестр экосистемы, контракты и планировщик интеграции.

## Что уже интегрировано в код

Нативный runtime NUN связывает Kloz, CO, SaintSI, ReaperCripple и ToolNG: проверяет платформенный контракт, поднимает ресурсы, запускает lifecycle, регистрирует health-компонент, ограничивает память/очереди/объём работы и применяет fail-closed политику. При ошибке bootstrap выполняется обратный rollback.

SAMBU и Klipot остаются host-инструментами и доступны целиком в исходных подмодулях. Их Python-код не притворяется freestanding-кодом ядра и не встраивается в нативный образ.

## Запуск одной командой

Клонируйте репозиторий с recursive submodules и выполните:

- Windows: one.cmd
- Linux/macOS: python3 one.py

Нужны CMake 3.20+, C11-компилятор, Python 3.10+; для Python-тестов установите pytest.

## Честный статус

Текущий результат — интеграционная host-сборка и модульная основа NUN, а не загрузочная ОС. Для bootable-образа дополнительно нужны конкретная CPU-архитектура, boot protocol, linker script, ранняя консоль, exception/interrupt vectors, управление страницами, драйверы и валидация в QEMU либо на целевом оборудовании.

Подробности: docs/ECOSYSTEM_INTEGRATION.md и ecosystem/manifest.json.
